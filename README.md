# Edward IP Attack

Network Flood Tool berbasis Python yang dirancang untuk melakukan pengujian beban jaringan secara agresif dan efisien.

Tools ini mendukung beberapa metode serangan lapisan jaringan (Layer 3 & Layer 4) dengan performa tinggi dan kontrol penuh terhadap target.

## Fitur Utama

- UDP Flood
- ICMP Flood
- Amplification UDP
- Multi-threading tinggi
- Monitoring paket real-time
- Sistem pencatatan log otomatis
- Antarmuka full screen
- Validasi IP target

## Instalasi

```bash
git clone https://github.com/EDWARD-BAIK/edward-ip-attack
cd edward-ip-attack
python3 edward-ip.py
